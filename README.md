## 🚀 Featured Projects

### 1. 🔍 RepoTalk — Chat with Any GitHub Repository
[![GitHub](https://img.shields.io/badge/Code-%230d1117.svg?logo=github&logoColor=white&style=flat-square)](https://github.com/S-V-Kartheek/repochat-ai)
- **What it does**: An AI-powered developer tool for natural-language Q&A over any GitHub repository
- **Under the hood**: AST-aware RAG pipeline with Tree-sitter chunking, hybrid vector search (Qdrant + BM25), and grounded LLM responses with file:line citations
- **Production features**: Clerk OAuth, SSE token streaming, multi-session persistent chat, Redis rate-limiting, and automated RAGAS answer quality scoring (faithfulness, relevancy, context precision)
- **Tech Stack**: React.js, Next.js, Node.js, FastAPI, Python, Qdrant, PostgreSQL, Redis

### 2. 🛡️ AEGIS AI — Explainable AI for Online Payment Fraud Detection
[![GitHub](https://img.shields.io/badge/Code-%230d1117.svg?logo=github&logoColor=white&style=flat-square)](https://github.com/S-V-Kartheek/Explainable-AI-for-Online-Payment-Fraud-Detection)
